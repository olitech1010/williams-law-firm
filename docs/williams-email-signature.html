How to Install in Your Email Client

Google Workspace / Gmail

  1. Click the Copy to Clipboard button above (or highlight and copy the signature box).
  2. Open Gmail and click the Gear icon (Settings) > See all settings.
  3. Scroll down to the Signature section and click Create new (or edit your existing signature).
  4. Paste (Ctrl+V or Cmd+V) into the text box and click Save Changes at the bottom.

Microsoft Outlook (Desktop & Web)

  1. Click Copy to Clipboard above.
  2. In Outlook, go to File > Options > Mail > Signatures (or Settings > Mail > Compose and reply on Outlook Web).
  3. Create a new signature, paste the signature, and select it as default for new messages and replies.

Apple Mail (macOS)

  1. In Apple Mail, open Settings / Preferences (Cmd + ,) > Signatures tab.
  2. Select your account, click +, and paste the copied signature.
  3. Ensure "Always match my default message font" is unchecked to preserve firm typography.
